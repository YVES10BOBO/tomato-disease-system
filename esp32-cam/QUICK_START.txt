STEP 4: SELECT CORRECT BOARD
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In Arduino IDE:
1. Go to: Tools → Board
2. Search: "ESP32"
3. Select: "AI-THINKER ESP32-CAM"

Settings:
   Upload Speed:     921600
   Flash Mode:       DIO
   Flash Frequency:  80MHz
   Partition Scheme: Huge APP (1.9MB OTA, 0.9MB SPIFFS)


STEP 5: UPLOAD TO ESP32-CAM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Hardware Setup:
1. Connect ESP32-CAM to computer via USB cable
2. Press and HOLD the "IO0" button on ESP32 board

Software:
1. Click Upload button (→ arrow icon)
2. Wait until you see "Connecting..."
3. THEN release the IO0 button
4. Wait for "Upload complete" message

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   ✅ "TOMATO GUARD - ESP32-CAM STARTING"
   ✅ "Camera initialized successfully"
   ✅ "DHT sensor initialized successfully"

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Upload fails:
   → Press IO0 button BEFORE clicking Upload
   → Try different USB cable
   → Try different USB port

❌ No Serial output:
   → Check Baud Rate is 115200
   → Check USB cable connection
   → Try different COM port

❌ WiFi not connecting:
   → Verify SSID spelling (case-sensitive)
   → Verify password correct
   → Check WiFi is 2.4GHz (not 5GHz)

❌ Camera error:
   → Check camera ribbon cable fully inserted
   → Try restarting ESP32 (power off/on)
   → Check cable is not damaged

❌ DHT sensor not reading:
   → Check pin 14 connection
   → Try adding 4.7kΩ pull-up resistor
   → Check sensor not damaged

   → Ready for manual capture button click
